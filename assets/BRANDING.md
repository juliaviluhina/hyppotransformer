# Branding assets

HyppoTransformer uses the same Hyppo mascot language as HyppoVisor: a chibi violet
hippo, gold freckles, expressive eyes, bold dark-purple outlines, saturated colors,
and a transparent background.

## HyppoTransformer mascot

The current repository asset is:

```text
assets/hyppotransformer.png
```

It preserves the HyppoVisor character while replacing the browser cards in the
lower-right area with a simple transformation symbol:

```text
circle → triangle
```

The geometric symbol communicates transformation without constraining the product
to Markdown, PDFs, CVs, or any single document type.

Current asset dimensions:

```text
1174 × 1340 PNG
```

## Usage guidance

- Keep the original Hyppo face, freckles, colors, outline, and proportions unchanged.
- Use the transformation symbol as the product-specific differentiator.
- Prefer a transparent background for README, documentation, and future UI assets.
- Create compact head or icon crops only when a product surface requires them.
- Do not replace the asset with a different mascot for each transformation type.
- Keep source artwork and generated crops separate so the master remains recoverable.

The source image is intentionally not embedded into transformation logic. Branding
assets are presentation resources and do not affect MCP behavior.
